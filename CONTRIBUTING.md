# Contributing

Corrections and reproducible real-world results are welcome.

Before submitting a result:

1. Read the benchmark methodology.
2. Identify the exact device, hardware revision, firmware, Home Assistant version,
   Assist pipeline, wake word, room, distance, and noise condition.
3. Include every attempt, including failures and retries.
4. Link public evidence where possible.
5. Remove passwords, tokens, account identifiers, serial numbers, IP addresses,
   and other private information.

Do not submit copied firmware, STL files, vendor documentation, or other material
without permission and a compatible license. Link to the original project instead.

Issues are for technical corrections and structured results, not general support.
